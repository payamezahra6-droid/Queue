# Simple Queue Using Array

## 📌 Description
This project demonstrates the implementation of a Simple Queue using an Array in Java. It follows the FIFO (First In, First Out) principle, where the first element inserted is the first one removed.

## 🎯 Objectives
- Understand the concept of a Queue.
- Learn the FIFO principle.
- Implement a Queue using an Array.
- Practice insertion and deletion operations in Java.

## 🛠️ Technologies Used
- **Language:** Java
- **IDE:** IntelliJ IDEA

## 📚 Concepts Learned
- Queue data structure
- Array implementation
- FIFO (First In, First Out)
- Enqueue operation
- Dequeue operation
- Front and rear pointers

## ⚙️ Operations
- **Enqueue:** Adds an element to the rear of the queue.
- **Dequeue:** Removes an element from the front of the queue.
- **Display:** Shows the elements of the queue.

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run the `Main.java` file.
